Questions

Windows says “protected your PC” (SmartScreen).

The app is not code-signed yet, so Windows warns about unrecognised apps. Click More info → Run anyway. The source is public on GitHub and the .exe is built there by an automated workflow.

Why can't the web app select my C: drive?

Chrome and Edge block websites from opening a drive root or system folders such as Windows and Program Files. Use the Windows app for whole drives, or pick sub-folders in the web app.

Does it upload my files or file names?

No. Scanning happens locally, in the app or in your browser tab. There is no server component.

How do I use the web app offline?

Open it once while online. After that it is stored in your browser and starts without a connection. In Chrome/Edge you can also use “Install app” in the address bar.

Does it work on macOS or Linux?

The web app does. The native app builds from source with cargo build --release, see the GitHub page.
