Space Hunter for Linux (x86_64)
================================

Run it straight from this folder:

    ./spacehunter              # or: ./spacehunter /path/to/scan

Install it for your user (app-menu entry, no root needed):

    ./install.sh               # remove later with ./install.sh --uninstall

Requirements: glibc 2.35+ (Ubuntu 22.04, Debian 12, Fedora 36 or newer),
OpenGL drivers, X11 or Wayland. The folder picker uses the XDG desktop portal
(present on GNOME, KDE and most desktops); you can always pass a path instead.

Source, issues and other platforms: https://github.com/quisen/SpaceHunter
Web version (no install): https://space-hunter.quisen.com.br/app/
